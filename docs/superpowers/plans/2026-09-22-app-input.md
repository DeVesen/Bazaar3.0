# app-input Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a new, standalone `app-input` Angular component (Haupt-App / `bazaar-app` frontend) — a `p-iftalabel`-based text field with optional left/right addons, a configurable-debounce value stream, and raw DOM-event passthrough.

**Architecture:** Single standalone Angular component (`OnPush`, signal-based `input()`/`output()`, no `ControlValueAccessor`) composing PrimeNG elements directly (`p-inputgroup`, `p-inputgroup-addon`, `p-iftalabel`, `pInputText`, `p-button`). No dependency on any other `app-...` component. Built in three code increments (core value/label flow → addons → raw events/attributes) plus one documentation task, each ending in a green test run.

**Tech Stack:** Angular 22 (standalone components, `@if`/`@for`/`@switch` control flow, signals), PrimeNG 22.1.1, RxJS (`toObservable`, `debounce`, `timer`), Vitest via `@angular/build:unit-test` (`npm test`).

**Spec:** [docs/spec/2026-09-22-app-input.md](../../spec/2026-09-22-app-input.md)

## Global Constraints

- Dumb Component: no business logic, no HTTP calls, no fachliche Entscheidungen inside `app-input` (`docs/components/overview.md`).
- PrimeNG-Grundregel: only PrimeNG elements/directives, no native unstyled HTML controls, no other `app-...` sub-component (`docs/components/overview.md`, spec "Was, wie, wo, warum").
- Value type is `string` only — no number/password mode (spec).
- No `ControlValueAccessor`, no two-way `[(value)]` — Parent owns `value` via one-way `input()`, component only emits (spec, confirmed against `input-group.ts`/`autocomplete-create.ts` precedent).
- Output names have no `on` prefix (project convention, confirmed) — **except** `blur`, which must be renamed to `blurred`: this codebase's `eslint.config.js` extends `angular.configs.tsRecommended`, which includes `@angular-eslint/no-output-native` and rejects an `@Output` literally named after a native DOM event (`blur` collides, `keyUp`/`keyDown`/`enter`/`valueChange`/`addonClick` do not — native names are lowercase `keyup`/`keydown`).
- `debounceMs: number`, default `800`, `0` = no debounce (spec).
- Selector `app-input`, component class name `Input` — file `src/app/shared/components/input/input.ts` (kebab-case selector prefix `app`, enforced by `@angular-eslint/component-selector` in `eslint.config.js`).
- Scope: `src/bazaar-app/frontend` only. Do not touch `src/advance-registration/frontend`.
- Test command: `npm test -- --watch=false` (run from `src/bazaar-app/frontend`; builder is `@angular/build:unit-test`, Vitest-based).

```typescript
import { ChangeDetectionStrategy, Component, effect, input, output, signal } from '@angular/core';
import { NgTemplateOutlet } from '@angular/common';
import { takeUntilDestroyed, toObservable } from '@angular/core/rxjs-interop';
import { FormsModule } from '@angular/forms';
import { debounce, filter, timer } from 'rxjs';
import { IftaLabelModule } from 'primeng/iftalabel';
import { InputGroupModule } from 'primeng/inputgroup';
import { InputTextModule } from 'primeng/inputtext';

/**
 * Eigenständige Text-Input-Komponente (docs/components/app-input/component.md), nach dem
 * PrimeNG-`p-iftalabel`-Muster aufgebaut. Verwendet ausschließlich PrimeNG-Elemente direkt,
 * keine anderen `app-...`-Komponenten (docs/spec/2026-09-22-app-input.md).
 */
@Component({
  selector: 'app-input',
  imports: [FormsModule, NgTemplateOutlet, IftaLabelModule, InputGroupModule, InputTextModule],
  templateUrl: './input.html',
  styleUrl: './input.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class Input {
  readonly label = input<string | undefined>(undefined);
  readonly value = input<string>('');
  /** Spec: default 800ms, 0 means no debounce. */
  readonly debounceMs = input<number>(800);

  readonly valueChange = output<string>();

  private readonly _rawValue = signal<string>('');
  readonly rawValue = this._rawValue.asReadonly();

  /** Keystroke stream feeding the debounced valueChange emit; undefined until first keystroke. */
  private readonly typed = signal<string | undefined>(undefined);

  constructor() {
    effect(() => {
      this._rawValue.set(this.value());
    });

    toObservable(this.typed)
      .pipe(
        filter((v): v is string => v !== undefined),
        debounce(() => timer(this.debounceMs())),
        takeUntilDestroyed(),
      )
      .subscribe((v) => this.valueChange.emit(v));
  }

  onTyped(value: string): void {
    this._rawValue.set(value);
    this.typed.set(value);
  }
}
```

# Component: app-input

Eigenständige Text-Input-Komponente (Haupt-App), aufgebaut nach dem PrimeNG-`p-iftalabel`-Muster.
Verwendet ausschließlich PrimeNG-Elemente direkt (`p-inputgroup`, `p-inputgroup-addon`,
`p-iftalabel`, `pInputText`) — keine anderen `app-...`-Komponenten, unabhängig von
[`input-group`](../input-group/component.md).

Quelle: [docs/spec/2026-09-22-app-input.md](../../spec/2026-09-22-app-input.md).

## Verhalten

- `label` gesetzt → Feld steckt in `p-iftalabel` mit Float-Label-Text. `label` nicht gesetzt →
  nacktes `pInputText`-Feld.
- `addonLeft`/`addonRight` (`InputAddon[]`) rendern je Eintrag ein eigenes `p-inputgroup-addon`
  links bzw. rechts, in Array-Reihenfolge. Leeres Array → kein Addon-Slot.
- Jedes Addon ist unabhängig vom `type` klickbar; Klick emittiert `addonClick` mit dem
  Addon-`key`.
- `valueChange` ist der gedämpfte Werte-Stream, Default-Debounce 800ms, einstellbar über
  `debounceMs` (`0` = kein Debounce).
- `enter`, `keyUp`, `keyDown`, `blurred` reichen das native Browser-Event sofort und ungedämpft
  durch.
- Pflichtfeld-Stern (`*`) und Feldfehler-Text (`docs/components/form` R-1) bleiben Aufgabe des
  Parent-Templates, außerhalb dieser Komponente.

## Parameter

| Parameter | Typ | Default | Bedeutung |
|---|---|---|---|
| `label` | `string \| undefined` | `undefined` | Float-Label-Text; steuert `p-iftalabel` vs. nacktes Feld |
| `value` | `string` | `''` | Aktueller Wert (Parent-gehalten, kein Zweiwege-Binding) |
| `debounceMs` | `number` | `800` | Verzögerung für `valueChange`, `0` = sofort |
| `addonLeft` | `InputAddon[]` | `[]` | Addons links vom Feld |
| `addonRight` | `InputAddon[]` | `[]` | Addons rechts vom Feld |
| `inputId` | `string \| undefined` | `undefined` | `id` des nativen `<input>` |
| `name` | `string \| undefined` | `undefined` | `name` des nativen `<input>` |
| `placeholder` | `string \| undefined` | `undefined` | Platzhaltertext |
| `type` | `string` | `'text'` | nativer `type` (`text`/`email`/`tel` …) |
| `required` | `boolean` | `false` | HTML-`required` |
| `disabled` | `boolean` | `false` | HTML-`disabled` |
| `readonly` | `boolean` | `false` | HTML-`readonly` |

`InputAddon`: `{ type: 'label' \| 'icon' \| 'button'; value: string; key: string; class?: string; style?: Record<string, string>; }`.
Icon-Werte folgen der Projekt-Konvention `pi pi-...`-CSS-Klasse.

## Events

| Event | Payload | Auslöser |
|---|---|---|
| `valueChange` | `string` | gedämpfter Werte-Stream |
| `enter` | — | Enter-Taste im Feld |
| `keyUp` | `KeyboardEvent` | natives `keyup` |
| `keyDown` | `KeyboardEvent` | natives `keydown` |
| `blurred` | `FocusEvent` | natives `blur` |
| `addonClick` | `string` (Addon-`key`) | Klick auf ein `addonLeft`/`addonRight`-Element |

## Abgrenzung

| Fall | Stattdessen |

| Passwort | `pInputPassword` direkt (Voranmelde-App) |
| Multi-Modus (Tastatur/Kamera/Numpad) | [`input-group`](../input-group/component.md) |
