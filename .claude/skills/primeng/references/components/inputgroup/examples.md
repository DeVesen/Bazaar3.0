# Angular InputGroup Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: Combines an input with addons such as buttons or text labels.
- `examples-button.md` — Button: Buttons can be placed at either side of an input element.
- `examples-checkbox-radio.md` — Checkbox & Radio: Checkbox and RadioButton components can be combined with an input element under the same group.
- `examples-float-label.md` — Float Label: FloatLabel visually integrates a label with its form element.
- `examples-ifta-label.md` — Ifta Label: IftaLabel is used to create infield top aligned labels.
- `examples-multiple.md` — Multiple: A group is created by wrapping the input and add-ons with the p-inputgroup component.
- `examples-select.md` — Select: A Select component can be used within an InputGroup alongside other add-ons and inputs.
