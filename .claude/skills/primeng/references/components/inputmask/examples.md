# Angular InputMask Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-autoclear.md` — AutoClear: When autoClear is set to false, the incomplete value is preserved on blur instead of being cleared.
- `examples-basic.md` — Basic: InputMask is used as a controlled input with ngModel properties.
- `examples-clearicon.md` — Clearicon: When showClear is enabled, a clear icon is displayed to clear the value.
- `examples-disabled.md` — Disabled: When disabled is present, the element cannot be edited and focused.
- `examples-filled.md` — Filled: Specify the variant property as filled to display the component with a higher visual emphasis than the default
- `examples-float-label.md` — Float Label: FloatLabel visually integrates a label with its form element.
- `examples-fluid.md` — Fluid: The fluid prop makes the component take up the full width of its container when set to true.
- `examples-format-patterns.md` — Format Patterns: Mask format can be a combination of the following definitions; a for alphabetic characters, 9 for numeric char
- `examples-ifta-label.md` — Ifta Label: IftaLabel is used to create infield top aligned labels.
- `examples-invalid.md` — Invalid: The invalid state is applied using the invalid property to indicate failed validation, which can be integrated
- `examples-optional.md` — Optional: When the input does not complete the mask definition, it is cleared by default.
- `examples-sizes.md` — Sizes: InputMask provides small and large sizes as alternatives to the base.
- `examples-slot-character.md` — Slot Character: Default placeholder for a mask is underscore that can be customized using slotChar property.
- `examples-unmask.md` — Unmask: The onUnmaskedChange event is invoked on every value change and emits the rawValue without the mask formatting
