# Angular Timeline Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-activity-feed.md` — Activity Feed: Display real-time activity streams with user avatars and contextual information.
- `examples-alignment.md` — Alignment: Content location relative the line is defined with the align property.
- `examples-basic.md` — Basic: Timeline receives the events with the value property as a collection of arbitrary objects.
- `examples-custom.md` — Custom: Sample implementation with custom content, styled markers, and rich event cards.
- `examples-horizontal.md` — Horizontal: TimeLine orientation is controlled with the layout property, default is vertical having horizontal as the alte
- `examples-interactive.md` — Interactive: Build interactive step-based workflows with progress tracking and state management.
- `examples-opposite.md` — Opposite: Additional content at the other side of the line can be provided with the opposite property.
- `examples-template.md` — Template: Sample implementation with custom content and styled markers.
