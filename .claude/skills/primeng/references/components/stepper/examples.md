# Angular Stepper Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: Stepper consists of a combination of StepList , Step , StepPanels and StepPanel components.
- `examples-linear.md` — Linear: When linear property is set to true, current step must be completed in order to move to the next step.
- `examples-stepsonly.md` — Stepsonly: Use Stepper with a StepList only for custom requirements where a progress indicator is needed.
- `examples-template.md` — Template: Stepper provides various templating options to customize the default UI design.
- `examples-vertical.md` — Vertical: Vertical layout requires StepItem as a wrapper of Step and StepPanel components.
