# Angular FileUpload Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-advanced.md` — Advanced: Advanced uploader provides dragdrop support, multi file uploads, auto uploading, progress tracking and validat
- `examples-auto.md` — Auto: When auto property is enabled, a file gets uploaded instantly after selection.
- `examples-basic.md` — Basic: Select and upload files with drag-and-drop support.
- `examples-custom-upload.md` — Custom Upload: Uploading implementation can be overridden by enabling customUpload property and defining a custom upload hand
- `examples-dropzone.md` — Dropzone: A custom dropzone can be built with the content and empty templates.
- `examples-image-preview.md` — Image Preview: Grid-based image preview with thumbnails.
- `examples-inputgroup.md` — InputGroup: FileUpload can be placed inside an InputGroup as an addon to combine it with other form controls.
