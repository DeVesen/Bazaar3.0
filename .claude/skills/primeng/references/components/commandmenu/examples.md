# Angular CommandMenu Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: CommandMenu requires a collection of menuitems via the model property.
- `examples-controlled.md` — Controlled: The search value can be controlled with two-way binding using [(search)] .
- `examples-custom.md` — Custom: Custom content can be displayed for each item using the item template.
- `examples-filter.md` — Filter: A custom filter function can be provided with the filter property.
- `examples-with-dialog.md` — With Dialog: CommandMenu can be used inside a Dialog to create a command palette experience.
