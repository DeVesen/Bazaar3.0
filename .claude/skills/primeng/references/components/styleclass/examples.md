# Angular StyleClass Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-animation.md` — Animation: Classes to apply during enter and leave animations are specified using the enterFromClass , enterActiveClass ,
- `examples-basic.md` — Basic: StyleClass applies enter and leave animations to a target element declaratively.
- `examples-hide-on-resize.md` — Hide On Resize: When hideOnResize is enabled, the leave animation is triggered automatically when resizing occurs.
- `examples-selector.md` — Selector: The target element is resolved with the selector option, which accepts keywords such as &#64;next , &#64;prev 
- `examples-toggle-class.md` — Toggle Class: StyleClass has two modes, toggleClass to simply add-remove a class and enter/leave animations.
