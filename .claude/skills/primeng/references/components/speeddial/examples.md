# Angular Speed Dial Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: SpeedDial displays related actions from a single trigger button.
- `examples-circle.md` — Circle: Items can be displayed around the button when type is set to circle .
- `examples-linear.md` — Linear: When type is set to linear (default), items are displayed in a line based on the direction property.
- `examples-mask.md` — Mask: Adding mask property displays a modal layer behind the popup items.
- `examples-quarter-circle.md` — Quarter Circle: Setting type as quarter-circle displays the items at one of four corners of the button based on the direction 
- `examples-semi-circle.md` — Semi Circle: When type is defined as semi-circle , items are displayed in a half-circle around the button.
- `examples-template.md` — Template: SpeedDial supports full customization of the trigger button and action items using the button and item templat
- `examples-tooltip.md` — Tooltip: SpeedDial can be combined with Tooltip to display labels for action items.
