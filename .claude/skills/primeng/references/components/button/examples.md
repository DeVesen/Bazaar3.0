# Angular Button Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-badge.md` — Badge: Badge component can be used to display a badge inside a button.
- `examples-basic.md` — Basic: Apply the pButton directive on a native &lt;button&gt; element with the label text inside.
- `examples-button-group.md` — Button Group: Multiple buttons are grouped when wrapped inside an element with ButtonGroup component.
- `examples-buttonset.md` — Buttonset: Multiple buttons are grouped when wrapped inside an element with p-buttonset class.
- `examples-disabled.md` — Disabled: When disabled is present, the element cannot be edited and focused.
- `examples-icons.md` — Icons: Place an icon as a child of the button.
- `examples-iconsonly.md` — Iconsonly: Set the iconOnly input to render the button as a square icon button without a label slot.
- `examples-link.md` — Link: The link input renders the button as a textual link.
- `examples-loading.md` — Loading: Indicate a busy state by setting disabled and rendering a spinner icon as a child while the request is pending
- `examples-outlined.md` — Outlined: Outlined buttons display a border without a background initially.
- `examples-raised.md` — Raised: Raised buttons display a shadow to indicate elevation.
- `examples-raised-text.md` — Raised Text: Text buttons can be displayed as raised for elevation.
- `examples-rounded.md` — Rounded: Rounded buttons have a circular border radius.
- `examples-severity.md` — Severity: The severity property defines the variant of a button.
- `examples-sizes.md` — Sizes: Button provides small and large sizes as alternatives to the standard.
- `examples-template.md` — Template: Custom content inside a button is defined as children.
- `examples-text.md` — Text: Text buttons are displayed as textual elements.
