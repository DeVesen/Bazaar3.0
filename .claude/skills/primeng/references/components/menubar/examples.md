# Angular Menubar Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: Menubar requires nested menuitems as its model.
- `examples-command.md` — Command: The command property defines the callback to run when an item is activated by click or a key event.
- `examples-router.md` — Router: Menu items support navigation via routerLink, programmatic routing using commands, or external URLs.
- `examples-submenu.md` — Submenu: Menuitems with nested items create cascading submenus.
- `examples-template.md` — Template: Custom content can be placed inside the menubar using the start and end templates.
