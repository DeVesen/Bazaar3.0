# Angular Sidebar Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-chat-application.md` — Chat Application: ChatGPT-style history sidebar with grouped sessions and hover-revealed delete action on each entry.
- `examples-dual-sidebar.md` — Dual Sidebar: Two sidebars on opposite sides with independent triggers.
- `examples-with-menu.md` — With Menu: Full application chrome with workspace switcher, grouped navigation and user footer.
- `examples-multi-sidebar.md` — Multi Sidebar: Two stacked sidebars: a hover-to-open icon bar and a fixed secondary panel.
- `examples-nested-menu.md` — Nested Menu: Menu items become collapsible to reveal a nested p-sidebar-menu-sub with deep trees and active-state tracking.
- `examples-responsive.md` — Responsive: Below 1024px the sidebar turns into an offcanvas overlay with a backdrop.
- `examples-variants.md` — Variants: Interactive playground for every sidebar variant, collapsible mode, side, overlay, open-on-hover and backdrop.
