# Angular TreeSelect Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: TreeSelect is used as a controlled component with ng-model directive along with an options collection.
- `examples-checkbox.md` — Checkbox: Selection of multiple nodes via checkboxes is enabled by configuring selectionMode as checkbox .
- `examples-clear-icon.md` — Clear Icon: When showClear is enabled, a clear icon is displayed to clear the value.
- `examples-disabled.md` — Disabled: When disabled is present, the element cannot be edited and focused.
- `examples-filled.md` — Filled: Specify the variant property as filled to display the component with a higher visual emphasis than the default
- `examples-filter.md` — Filter: Filtering is enabled by adding the filter property, by default label property of a node is used to compare aga
- `examples-float-label.md` — Float Label: A floating label appears on top of the input field when focused.
- `examples-fluid.md` — Fluid: The fluid prop makes the component take up the full width of its container when set to true.
- `examples-ifta-label.md` — Ifta Label: IftaLabel is used to create infield top aligned labels.
- `examples-invalid.md` — Invalid: The invalid state is applied using the ⁠invalid property to indicate failed validation, which can be integrate
- `examples-lazy.md` — Lazy: Lazy loading is useful when dealing with huge datasets, in this example nodes are dynamically loaded on demand
- `examples-multiple.md` — Multiple: More than one node is selectable by setting selectionMode to multiple .
- `examples-sizes.md` — Sizes: TreeSelect provides small and large sizes as alternatives to the base.
- `examples-template.md` — Template: TreeSelect offers multiple templates for customization through templating.
- `examples-virtualscroll.md` — Virtualscroll: VirtualScrolling is an efficient way of rendering the options by displaying a small subset of data in the view
