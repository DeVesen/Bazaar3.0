# Angular IconField Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: An input field with an embedded leading or trailing icon.
- `examples-clickable.md` — Clickable: Icons inside InputIcon can be interactive with event handlers like click.
- `examples-floatlabel.md` — Floatlabel: FloatLabel visually integrates a label with its form element.
- `examples-iftalabel.md` — Iftalabel: IftaLabel is used to create infield top aligned labels.
- `examples-sizes.md` — Sizes: IconField is compatible with the size setting of the input field.
- `examples-template.md` — Template: An eye icon is displayed by default when the image is hovered in preview mode.
