# Angular Gallery Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: Displays a collection of images with a lightbox viewer.
- `examples-grid.md` — Grid: Gallery can be used as a lightbox by combining it with a grid of thumbnails.
- `examples-single.md` — Single: Click on the image to open it in a fullscreen dialog without thumbnails or navigation buttons.
- `examples-thumbnails.md` — Thumbnails: Add a p-gallery-footer with p-gallery-thumbnail to render a thumbnail strip for quick navigation.
- `examples-toolbar.md` — Toolbar: Add a p-gallery-header with action sub-components like pGalleryRotateLeft , pGalleryZoomIn , pGalleryDownload
