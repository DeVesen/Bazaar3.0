# Angular ContextMenu Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: ContextMenu is attached to a target element using the target property and activated with a right-click.
- `examples-command.md` — Command: The function to invoke when an item is clicked is defined using the command property.
- `examples-document.md` — Document: Setting the global property to true attaches the context menu to the document.
- `examples-router.md` — Router: Menu items support navigation via routerLink, programmatic routing using commands, or external URLs.
- `examples-submenu.md` — Submenu: Submenus are defined by nesting menu items within the items property of a parent menu item.
- `examples-table.md` — Table: Table has built-in support for ContextMenu, see the ContextMenu demo for an example.
- `examples-template.md` — Template: ContextMenu offers item customization with the item template that receives the menuitem instance from the mode
