# Angular Message Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: An inline message for informational, success, warning, or error feedback.
- `examples-closable.md` — Closable: Enable closable option to display an icon to remove a message.
- `examples-dynamic.md` — Dynamic: Multiple messages can be displayed using the standard for block.
- `examples-form.md` — Form: Validation errors in a form are displayed with the error severity.
- `examples-icon.md` — Icon: The icon of a message is specified with the icon property or the icon template.
- `examples-life.md` — Life: Messages can disappear automatically by defined the life in milliseconds.
- `examples-outlined.md` — Outlined: Configure the variant value as outlined for messages with borders and no background.
- `examples-severity.md` — Severity: The severity option specifies the type of the message.
- `examples-simple.md` — Simple: Configure the variant value as simple for messages without borders and backgrounds.
- `examples-sizes.md` — Sizes: Message provides small and large sizes as alternatives to the base.
- `examples-variant.md` — Variant: Configure the variant value as outlined or simple .
