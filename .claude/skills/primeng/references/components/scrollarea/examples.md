# Angular Scroll Area Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: A custom scrollable container with styled scrollbars.
- `examples-both-scrollbars.md` — Both Scrollbars: Both vertical and horizontal scrollbars are displayed when the content overflows in both directions.
- `examples-custom.md` — Custom: Scrollbar and thumb elements can be customized using classes on the sub-components.
- `examples-scroll-fade.md` — Scroll Fade: The mask property adds a gradient fade effect at the scroll edges.
- `examples-horizontal.md` — Horizontal: ScrollArea supports horizontal scrolling for content that extends beyond the horizontal viewport.
- `examples-variant.md` — Variant: Change the visibility behavior of scrollbars with the variant property.
