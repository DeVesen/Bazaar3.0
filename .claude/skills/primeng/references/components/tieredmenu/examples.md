# Angular TieredMenu Component — Beispiele (Index)

Nur die benötigte Datei lesen.

- `examples-basic.md` — Basic: TieredMenu requires a collection of menuitems as its model .
- `examples-command.md` — Command: The command property defines the callback to run when an item is activated by click or a key event.
- `examples-popup.md` — Popup: Popup mode is enabled by adding popup property and calling toggle method with an event of the target.
- `examples-router.md` — Router: Menu items support navigation via routerLink, programmatic routing using commands, or external URLs.
- `examples-template.md` — Template: TieredMenu offers item customization with the item template that receives the menuitem instance from the model
